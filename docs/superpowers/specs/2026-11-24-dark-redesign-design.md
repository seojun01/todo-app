# 다크 리디자인 (차콜 + 오렌지) — 짧은 설계

## 왜
지금 디자인이 밋밋하고, 한눈에 보기 어렵다 (한 줄에 칩이 최대 8개). 기능은 건드리지 않고 겉모습만 바꾼다.

## 목표
- 차콜 바탕 + 주황 포인트의 다크 테마, 카드형 할 일 (시안 B 구조, 5번 팔레트)
- 오늘 화면에서 "지금 뭘 할지"가 바로 보이게: 진행률 링 + 묶음(기한 지남 / 중요 / 나머지)
- 모든 화면(수신함·예정·캘린더·설정 포함)이 같은 색·카드 톤을 따른다

## 하지 않을 것
- 할 일 생성·완료·동기화·알림 등 동작 변경, 기존 클래스명·DOM 제거/이름 변경
- 수신함·예정·캘린더·설정은 DOM을 바꾸지 않는다. 대신 CSS로 카드·간격·글자 위계·헤더까지 전부 새 디자인으로 다시 입힌다 (사용자 승인: 전체 화면 리디자인)
- 라이트 모드 유지 (아래 내 결정)

## 접근 (고른 것: 2번)
1. CSS만 — 안전하지만 묶음·진행률을 못 만든다.
2. **CSS + 오늘 화면에만 요소 추가** — 선택. 기존 로직·클래스는 그대로, 요소만 덧붙인다.
3. 전체 화면 재구성 — 위험·작업량이 커서 제외.

## 디자인
- 팔레트 (내 값, 대비 4.5:1 이상 확인 필요): 바탕 `#141414`, 카드 `#1F1F1F`, 선 `#333`, 글자 `#F2F2F2`, 보조 글자 `#A3A3A3`, 포인트 `#FF7A1A` (위 글자 `#1E0C00`), 중요 `#FFC24D`, 기한 지남 `#FF6B5E`.
- `styles.css`의 색 변수만 바꾸고 `prefers-color-scheme` 라이트/다크 분기는 다크 한 벌로 합친다. `color-scheme: dark`.
- 할 일 한 줄: 둥근 카드, 우선순위는 왼쪽 색 막대(색 + 기존 ⚑P1 글자 유지), 칩은 더 작고 흐리게.
- 오늘 화면: 맨 위에 "오늘 N개 남았어요" + 진행률 링(오늘 완료/전체). 기존 "기한 지남" 구역과 오늘 목록(한 개의 `ul`)은 그대로 둔다. **"지금 중요/나머지" 별도 묶음은 만들지 않는다**: 직접 정한 순서(sortKey)가 우선순위보다 앞서고 순서 바꾸기가 목록 하나 기준이라, 나누면 순서 기능이 깨진다. 대신 P1·P2 카드는 왼쪽 색 막대와 굵은 제목으로 눈에 띄게 한다 (2026-11-24 구현 계획 수립 중 변경).
- 링·묶음은 글로도 같은 정보를 준다(색만으로 구분 금지). 포커스 표시·reduced-motion 유지.
- `theme-color`, `manifest`의 `background_color`/`theme_color`를 새 바탕색으로.

## 내 결정 (확인 필요)
- 다크 단일 테마(라이트 제거) — 코드가 줄고 방향이 하나로 모인다.
- 링 숫자는 "오늘 완료 / 오늘 전체"로 정의.

## 검증
`npm run typecheck`, `npm test`, `npm run test:e2e`(접근성 axe 포함) 통과. node_modules가 없어 `npm install` 필요.

## 빌더에게 남김
각 화면 CSS 세부 값, 링 구현(conic-gradient 또는 SVG), 모바일 폭 확인.
